description: Run project onboarding to understand the codebase
---

Use the `project-onboarding` skill to explore the project and produce a TLDR summary.

Steps:

1. Read key project files (README, flake.nix, package manifests, Makefile, etc.).
2. Inspect the top-level directory structure.
3. Ask clarifying questions if needed.
4. Generate a concise TLDR summary.
5. Ask the user to confirm or correct the summary before starting work.

Do not modify files. This is a read-only exploration.
