Start a Test-Driven Development planning session.

The `tdd-coach` agent will help you:

1. Clarify and refine the requirements.
2. Define measurable success metrics.
3. Design test cases before writing production code.
4. Break the implementation into small, testable steps.
5. Track progress using a TODO list.

Be ready to describe what you want to build. The agent will ask clarifying questions and guide you through the TDD cycle: red → green → refactor.
